# Poke Idle Desktop — Downloads

Aplicativo para Windows que reúne quatro sessões independentes do Poke Idle em uma janela.

**[Baixar a versão mais recente para Windows 64 bits](https://github.com/Overstrider/poke-idle-desktop-releases/releases/latest)**

## Como usar

1. Abra a página de download e baixe o arquivo `Poke-Idle-Desktop-…-win-x64.exe`.
2. Execute o arquivo. O Electron está incluído; não é necessário instalar Node.js ou dependências.
3. Faça login nas contas desejadas. Clique em um jogo menor para trazê-lo ao painel principal.

O executável é portátil, sem instalador. Ao abrir, ele extrai os componentes de execução para uma pasta temporária. É necessário acesso à internet para jogar.

## Recursos

- Quatro contas com sessões e configurações independentes.
- Troca animada entre o jogo principal e os jogos secundários.
- Hunts por nome, elemento e nível, com sugestões de nomes.
- Auto de hunts por nível, proteção de XP e recuperação da equipe.
- Venda de Pokémon com filtros de raridade e IV, preservando shiny e Pokémon protegidos.
- Troca e compra automáticas de Poké Balls com controles independentes.
- Ações para cura, Depot e Loja.
- HUD configurável e histórico local por personagem, Pokémon, data e hora.

## Dados locais

Perfis, preferências e o banco SQLite ficam em `%APPDATA%\PokeIdleDesktop`. Eles não estão incluídos no download. Trocar o executável por uma versão nova preserva essa pasta.

## Sobre este repositório

Este repositório público é exclusivo para distribuição dos executáveis e notas de versão. O repositório de desenvolvimento não é publicado aqui.

As releases incluem `SHA256SUMS.txt` para conferir a integridade do download. Esta build ainda não possui assinatura digital.
